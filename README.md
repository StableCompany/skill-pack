# Integrator Skill Pack

Claude skills for the person who runs the week: weekly meeting prep, one-on-ones, meeting notes to actions, same-page meetings with your Visionary, clarity breaks, quarterly planning prep, process maps, SOPs, and messages for every audience. Made by Katie Sandquist and The Stable Company. Every skill works from one folder you own, shows you its plan before it files anything, and never sends a message on its own.

## Add it to Claude, about two minutes

1. In Claude, open **Customize**, then **Plugins**.
2. Choose **Add**, then **Add marketplace**.
3. Paste `StableCompany/integrator-skill-pack-plugin` and add it.
4. Find **Integrator Skill Pack** and install it. Turn on **Sync automatically** so you get each improvement as we make it.

Then say **"What can this pack do?"** or **"Start here."**

In Claude Code:

```
/plugin marketplace add StableCompany/integrator-skill-pack-plugin
/plugin install integrator-skill-pack@stable-company
```
