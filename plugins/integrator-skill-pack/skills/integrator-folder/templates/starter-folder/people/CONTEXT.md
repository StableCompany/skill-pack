# People
One file per person I meet with one-on-one: `first-last.md`, lowercase, with a hyphen (`sam-rivera.md`).
- **Written by:** one-on-one (starts and updates each file). meeting-to-actions adds dated lines under `## From meetings`, as `- YYYY-MM-DD (<type> meeting): <note>`. clarity-break adds a neutral question under `## Next time`, after my yes.
- **Read by:** one-on-one, meeting-to-actions, cascade.
- **Headings, in this order:** The basics · Open commitments · Next time · Next agenda · Wins · Growth · Kept by choice · Patterns · From meetings · 1:1 log.
- **The log only grows,** newest entry on top. Past entries are never rewritten.
- **Write every line as if the person might read it.** Health, family and personal life stay out unless I ask to keep one detail.
- **My Visionary has no file here.** Those items live in `visionary/`.
- **Done looks like:** I can walk into a one-on-one with this file alone.
