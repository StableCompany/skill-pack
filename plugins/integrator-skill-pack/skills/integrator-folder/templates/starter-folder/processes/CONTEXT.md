# Processes
One folder per process, named with our name for it, lowercase, with hyphens: `processes/new-client-onboarding/`.
- `map.md` is the source of truth (process-map). `map.html` is its printable picture.
- Documents written from the map sit beside it: `sop.md`, `checklist.md`, `how-we-do.md`, `policy.md`, `onboarding-<seat>.md` (process-doc). `sop.html` is the printable SOP.
- **Every step in a document carries its map step,** like `(map 4)`.
- **When the process changes,** update `map.md` first, then rewrite the documents from it.
- **Describe the process.** Never grade a person.
