# Meetings
Prep sheets and notes, one file each, date first.
- `YYYY-MM-DD-weekly-prep.md`: the prep sheet, named for the meeting date. Written by weekly-meeting-prep.
- `YYYY-MM-DD-<type>.md`: notes from a meeting, where type is weekly, quarterly, team, project, or a short word I choose. Written by meeting-to-actions.
- `YYYY-MM-DD-<type>-transcript.md`: a transcript, kept only if I ask. Notes link to it and never paste it.
- **Read by:** weekly-meeting-prep, one-on-one, same-page-prep, quarterly-prep.
- **Notes keep a dated "Priority updates" section.** weekly-meeting-prep counts the days since each priority's last update from it.
- **Done looks like:** every to-do and issue that came from a meeting points back to its notes file.
