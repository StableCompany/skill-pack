# Integrator Skill Pack

Sixteen Claude skills for the person who runs the week, made for HERverse 2026 by Katie Sandquist and The Stable Company. Every skill reads and writes one folder the Integrator owns, shows its plan before it files anything, and never sends a message on its own. Start by saying "What can this pack do?" or "Start here."

In Claude Code: `/plugin install stable-company-skill-pack --marketplace StableCompany/skill-pack`
